# Milestone 1: Walking Skeleton

## תכנון

### המטרה
הדף והפונקציה באוויר ב-Vercel, באותה כתובת, ומדברים זה עם זה. המפתח שמור ב-Vercel, אבל עוד בלי AI.

### החלטות שנקבעו מולי
- מצבי המסך: רק **התחלה** ו**בדיחה**. טעינה ושגיאה נבנים ב-Milestone 2.
- בדיקה: בכתובת של Vercel, אחרי push. בלי `vercel dev` בשלב הזה.

### הקבצים
| הקובץ | מה בו |
|---|---|
| `index.html` | המסך הראשי, עם ה-CSS וה-JavaScript בתוכו. `lang="he"`, ‏`dir="rtl"` |
| `api/joke.js` | `export default { async fetch(request) }`. רק POST, מחזירה תמיד JSON |
| `package.json` | `"type": "module"`, בלי dependencies |

### המסך (לפי DESIGN.md ו-mockups.png)
- רקע שמש `#FFE15A`, ‏`bg-dots.svg` חוזר על כל המסך, ‏`bg-doodles.svg` פעם אחת למעלה.
- מלמעלה למטה: לוגו (רוחב 300), שורת הסבר, תווית "על מה הבדיחה?", תיבה (`maxlength="100"`, "למשל: חתולים"), כפתור "תנו לי בדיחה!", בועה, ושורת תחתית "מיישם AI ואוטומציה · 53500".
- גופנים: Fredoka לממשק, Playpen Sans Hebrew לבדיחה, עם גיבוי ל-system-ui.
- הבועה עם `data-state` ו-`aria-live="polite"`:
  - `idle`: ‏`mascot-idle.svg` במרכז, קופצת 5px כל 2.4 שניות. "לוחצים על הכפתור, והבדיחה מופיעה כאן".
  - `joke`: ‏`mascot-joke.svg` בפינה הימנית העליונה, חצי בחוץ, ברוחב 86 ומסובבת 8 מעלות, מתגלגלת מצחוק ארבע פעמים. הבדיחה בכתב יד, בגודל 25. הכפתור: "עוד בדיחה!".
- צללים קשים בלי טשטוש, הטיות קלות, טבעת פוקוס כחולה, ו-`prefers-reduced-motion` מבטל את כל התנועה.
- רוחב תוכן מקסימלי 440, ‏18 בצדדים, ‏14 בין רכיבים. נבנה קודם לרוחב 375.

### הזרימה
1. שליחת הטופס: `fetch("/api/joke", { method: "POST", body: JSON.stringify({ topic }) })`.
2. הפונקציה: גוף שבור או נושא ריק נחשבים "אין נושא". מחזירה 200 עם
   `{ "joke": "בדיחה זמנית מהשרת: [הנושא]. המפתח: נמצא" }`, או "המפתח: חסר".
   בקשה שאינה POST: ‏405 עם `{ "error": "..." }`.
3. `console.log` קצר לכל בקשה (הנושא, והאם יש מפתח), כדי לראות שורה ב-Logs.
4. הדף מציג את `joke` עם `textContent` ועובר ל-`data-state="joke"`.
- בלי כותרות CORS ובלי טיפול ב-OPTIONS. הפונקציה לא מחזירה את המפתח, רק כן או לא.

### הפריסה (ביד, אצלי)
0. עוד אין לי חשבון ב-Vercel: נרשמים ב-vercel.com עם Continue with GitHub, בתוכנית Hobby.
